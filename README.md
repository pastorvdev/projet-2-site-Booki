# projet-2-site-Booki

Ce projet est un site de réservation d'hergements en ligne.
Les utilisateurs peuvent effectuer des recherches sur les destinations de leur choix.
Seule la partie Front-end du site est développé en HTML et CSS, sans framework comme tailwind ou bootstrap.

## Objectif du projet:

1- Effectuer le découpage maquette en utilisant Figma.
2- Créer un dépôt local git, et ajouter une branche dev pour les modifications.
3- Integrer la structure du site Booki avec HTML.
4- Mise en place du style de la maquette avec le CSS.
5- Appliquer le responsive design desk to mobile.
6- Valider le code sur W3C validator.
7- Effectuer un merge sur la branche principale.
